# 易遊網機票爬蟲-gui (eztravel_scraper-gui) V1.2.0

這是一個具備現代化圖形介面 (GUI) 的易遊網 (ezTravel) 機票監控工具，專為需要直觀操作、自動記錄與多平台執行的使用者設計。

## 🌟 功能特色
- **Excel 自動記錄**：支援將每日市場票價自動記錄至 Excel 表格，並可設定記錄前 N 名最低票價，且不破壞使用者原本的 Excel 公式。
- **全域一鍵儲存**：全新的儲存邏輯，點擊一次即可同步所有分頁設定與瀏覽器憑證。
- **UI 比例優化**：針對台灣使用者手動調整的最佳視窗比例 (1000x880)，確保所有欄位（含 Email 通知）完整顯示不遮擋。
- **繁體中文優化**：強制指定 Windows 「微軟正黑體」，徹底解決介面字體回退至簡體字的問題。
- **自動化監控**：支援自定義分鐘數的自動循環監控，具備即時倒數計時與強制停止功能。

## 🛠 操作教學
1. **下載執行檔**：
   - 前往 [Releases](https://github.com/samson1357924/eztravel_scraper-gui/releases) 下載適合你系統的執行檔。
2. **基本設定**：
   - 啟動程式後，進入 **「LINE 設定」** 或 **「Email 設定」** 填入你的 Token 或帳密，並點擊開關啟用。
   - 進入 **「Excel 記錄」** 分頁設定檔名與記錄順位。
   - 在下方獨立方塊中設定目標價格、日期與監控頻率。
   - 在右側 **「瀏覽器憑證」** 區貼入轉換後的 cURL 程式碼。
3. **執行**：
   - 點擊 **「儲存設定」** 確保所有變更已寫入。
   - 點擊 **「執行單次抓取」** 或 **「啟動自動監控」**。
